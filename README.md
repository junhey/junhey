# Jun He

腾讯海外业务工程师。做前端与跨端（Web、Smart TV / Roku），用 Rust 和 Swift 做能装上的桌面工具，并把 AI 工程实践写成公开课程。

## 现在在做什么

公开主项目是 [cmds](https://github.com/junhey/commands)：一个单文件的交互式 shell。打字时用历史补全，Tab 打开候选，提示符按模块拼。

## 作品

### 桌面工具

- [commands](https://github.com/junhey/commands) — 可安装的交互式 shell
- [json-toolkit](https://github.com/junhey/json-toolkit) — 浏览器里的 JSON 工具箱，核心用 Rust
- [clipsync-app](https://github.com/junhey/clipsync-app) — 菜单栏剪贴板，可用自己的 GitHub 同步
- [apple-app-organizer](https://github.com/junhey/apple-app-organizer) — 扫描 macOS 邮件、信息、备忘录等，默认只读，确认后才清理

### AI 工程

- [ai-learn](https://github.com/junhey/ai-learn) — 九阶段 AI 工程师课程，可构建成阅读页和幻灯片
- [ai-start](https://github.com/junhey/ai-start) — 给开发者的 AI 课件

### 跨端

- [roku-developer-skill](https://github.com/junhey/roku-developer-skill) — 给编程助手用的 Roku / BrightScript 说明

### 早期作品

2016–2021 的笔记和资料还在，已经停更：[wxapp](https://github.com/junhey/wxapp)、[studyNotes](https://github.com/junhey/studyNotes)、[softwareDesigner](https://github.com/junhey/softwareDesigner)。
